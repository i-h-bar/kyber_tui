# kyber_tui

Rough auth flow
```
CLIENT                                SERVER                                                                                                                                                                                                                                                                                                    
|                                     |                                                                                                                                                                                                                                                                                                       
|-- Kyber KEM handshake ------------->|  (establishes shared AES-256 key)                                                                                                                                                                                                                                                                     
|                                     |                                                                                                                                                                                                                                                                                                       
|-- encrypt(hashed_password, AES) --->|                                                                                                                                                                                                                                                                                                       
|   signed with client SPHINCS+ key   |                                                                                                                                                                                                                                                                                                       
|                                     |  verify signature, check password                                                                                                                                                                                                                                                                     
|                                     |  generate token                                                                                                                                                                                                                                                                                       
|                                     |  sign token with SERVER SPHINCS+ key                                                                                                                                                                                                                                                                  
|<-- encrypt(token, AES) -------------|                                                                                                                                                                                                                                                                                                       
|                                     |                                                                                                                                                                                                                                                                                                       
|-- encrypt(token, AES) ------------->|  subsequent requests                                                                                                                                                                                                                                                                                  
|                                     |  verify token signature = server's key                                                                                                                                                                                                                                                                
```
